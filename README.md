# Cryptography Notes

These notes are part of my ongoing study of cryptography.

The main goal of this repository is to organize what I learn while studying cryptography, mathematics, and post-quantum cryptography during my master's degree and beyond. Rather than writing a finished textbook from the start, I intend to build these notes gradually as my understanding of the subject develops.

The material will begin with the mathematical foundations needed to understand modern cryptography and progressively move toward classical cryptographic constructions, security concepts, computational problems, and post-quantum cryptography.

The general path is roughly:

**Mathematics → Hard Problems → Security Assumptions → Cryptographic Constructions → Post-Quantum Cryptography**

Topics may include:

- Number theory
    
- Abstract algebra
    
- Linear algebra
    
- Probability
    
- Computational complexity
    
- Classical cryptography
    
- Security definitions and reductions
    
- Lattice-based cryptography
    
- Code-based cryptography
    
- Multivariate cryptography
    
- Hash-based cryptography
    
- Other topics related to post-quantum cryptography
    

The emphasis is not only on understanding **how cryptographic schemes work**, but also on understanding the mathematics and computational problems that make them secure.

Whenever possible, the notes will include:

- Definitions
    
- Mathematical intuition
    
- Worked examples
    
- Proofs or proof sketches
    
- Connections between concepts
    
- Small educational implementations
    
- Exercises
    
- References to books and research papers
    

## About these notes

This repository should be considered a **living set of study notes**, not an authoritative reference.

Some sections may be incomplete, reorganized, rewritten, or corrected as I learn more. Earlier explanations may change significantly as my understanding improves.

Part of the purpose of making these notes public is precisely to preserve that process.

If they happen to be useful to someone else studying cryptography, even better.

## Disclaimer

The implementations contained in this repository, when present, are intended for **educational purposes only**.

They should not be considered secure implementations or used in production systems.
